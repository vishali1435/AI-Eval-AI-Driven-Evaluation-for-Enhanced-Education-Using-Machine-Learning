About AI-Eval

Automated Subjective Answer Sheet Grading via Machine Learning & NLP

System Architecture & Methodology

Examinations play a critical role in universities and educational institutions. Traditional subjective evaluation is manual, tedious, and prone to evaluator subjectivity. AI-Eval delivers an end-to-end automated platform that processes scanned handwritten paper sheets, applies Optical Character Recognition (OCR), extracts rich linguistic features, and applies calibrated Machine Learning algorithms to compute accurate and fair grades.

1. OCR Processing

Scanned student sheets are preprocessed using contrast normalization, grayscale conversions, and Tesseract OCR to digitize handwritten text.

2. NLP Feature Extraction

Features include Keyword Matching with WordNet synonym expansion, Semantic Similarity using CountVectorizer & Cosine Similarity, and Grammar analysis.

3. Trained ML Scoring

A machine learning model (Random Forest / Regression) synthesizes multi-dimensional criteria into predicted marks matching pedagogical standards.

4. Plagiarism Detection (≤ 50% Cap)

Cross-submission text similarity analysis prevents cheating while strictly complying with the 50.0% cap on similarity scores.
